# 校园网一键登录工具

Windows 桌面客户端，适配南京工业大学 Dr.COM 门户，支持中国移动和通过路由器认证。电脑与程序持续运行时，默认每 30 秒发送小体积 HTTP 探测，确认需要认证后自动恢复。

## 首次使用

1. 运行 `release/CampusNetLogin.exe`。
2. 输入原始学号和统一身份认证密码，服务选择“中国移动”。已填 `@cmcc` 时不会重复添加；电脑端前缀由门户配置决定，当前现场为 `,0,学号@cmcc`。
3. 电脑连接宿舍路由器时勾选“通过路由器连接”。新配置默认勾选，旧配置保留原直连方式，升级后需自行勾选。
4. 勾选“自动保活与重连”，点击“保存账号”；程序按设置启动监控。也可以点击“一键登录”。只有外网复测成功才显示在线。

[学校学生宿舍上网指南](https://network.njtech.edu.cn/info/1035/1421.htm)确认宿舍支持中国移动，账号为学号，登录密码为自己设置的统一身份认证密码；运营商套餐应先完成绑定。

## 日常运行

- 在线时发送探测流量，不重复登录。单个探测地址故障会尝试其他地址。
- 外网全部探测失败后查询门户。门户明确未认证或外网被重定向到校园门户才认证；门户可访问但外网故障时继续检测。
- 临时失败等待 30、60、120、240、300 秒，最长 300 秒，恢复后回到 30 秒。密码错误、账号停用、套餐异常会暂停自动认证，修改配置或手动登录后恢复。
- 关闭窗口继续托盘运行；双击托盘图标恢复窗口，托盘菜单或窗口“退出程序”停止。退出时可能需等待当前请求结束。
- 注销和本机下线会先暂停监控；即使保存账号或重新勾选自动选项也保持暂停，直到手动登录。
- “注销并重新登录”串行注销当前出口，再刷新身份并认证。无需持有 `user_index`。
- GUI 和 `--monitor` 共用单实例锁。程序已在运行时第二次启动不会另开认证循环；独立后台模式运行时先停止它，再打开 GUI 修改配置。

连通性流量不能保证延长校园网强制到期会话，到期后以重新认证恢复。电脑睡眠、断电或程序退出期间无法保活。

## 配置和日志

配置保存在 `%USERPROFILE%/.campus_net_login/config.json`；密码使用 Windows DPAPI 加密，保持原存储方式，只能由原 Windows 用户解密。

旧版任一自动选项开启会迁移为 `auto_maintain=true`，两项关闭则保持关闭。新选项保存在 `auto_maintain` 和 `router_mode`，重启后保留服务和选项。直连模式仍使用高级选项 Portal IP，默认 `10.255.20.10:801`；路由器模式从 `http://a.njtech.edu.cn/` 获取真实出口身份及门户配置，不用电脑局域网 IP/MAC 替代。缺少真实身份、身份矛盾或配置无法解析时显示原因并等待，不猜测认证参数。

日志保存在 `%USERPROFILE%/.campus_net_login/logs/monitor.log`，最多保留当前文件及 3 个历史文件。记录掉线发现时间、认证状态、退避和恢复耗时；无法确定原因时标记“未知”。日志不保存密码或包含密码的请求 URL，可能包含出口 IP/MAC，分享前可自行遮盖这些设备信息。

## 源码运行及构建

```powershell
python -m pip install -r requirements.txt
python app.py
python app.py --monitor
python app.py --once
```

`--once` 执行一次检测和按需认证，退出码 0 表示外网已验证在线，1 表示未恢复，2 表示已有实例运行、本次未执行检测。`--monitor` 使用保存的配置持续运行，控制台中 Ctrl+C 停止；若关闭自动选项则不自动认证。独立后台运行不会在退出 GUI 后被另外创建。

Windows 下运行 `build.bat`，脚本创建 `build/.venv` 隔离环境、安装依赖、运行测试/编译检查，再生成 `release/CampusNetLogin.exe`。运行 EXE 无需安装 Python。构建工具版本见 `requirements-build.txt`；不需要确认服务器、管理员权限或新增开机任务。

完整本地验收可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify_windows.ps1`。它执行构建、源码检查及真实 EXE 的托盘/锁/退出检查；包测试使用临时空账号配置并只读探测外网，需要当前已联网，未联网时会明确失败。

## 现场验收

1. 电脑通过工具认证，确认同一路由器上的手机同时可以访问外网。
2. 电脑和程序持续运行至少 24 小时，包含夜间闲置；记录发现掉线的时间、恢复时间和日志认证状态。
3. 确认强制到期后自动恢复、主动注销不会自动登录、托盘持续运行、退出后停止。
4. 若密码或套餐错误，先修正账号/绑定状态，再保存配置或手动登录。

当前本地验证和只读现场查询不代表真实登录及长期效果已验收。24 小时观察也不能证明永久不掉线。

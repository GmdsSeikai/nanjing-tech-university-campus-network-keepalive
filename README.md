# 南京工业大学校园网保活工具

**Nanjing Tech University Campus Network Keepalive Tool**

Windows 桌面客户端，适配南京工业大学 Dr.COM 门户，支持中国移动和通过路由器认证。电脑与程序持续运行时，默认每 30 秒发送小体积 HTTP 探测，确认需要认证后自动恢复。

## 功能

- 一键登录：使用学号和统一身份认证密码完成校园网认证，支持中国移动账号后缀处理。
- 自动保活与断线重连：定时检测外网连通性，确认认证到期后自动重新登录；临时失败按退避间隔重试。
- 宿舍路由器认证：从学校门户获取当前出口身份，支持电脑通过宿舍路由器接入校园网。
- 系统托盘运行：关闭窗口后继续监控，可从托盘恢复窗口或退出；单实例锁避免重复认证循环。
- 本地配置与日志：使用 Windows DPAPI 加密保存密码，记录检测、认证和恢复状态。
- 命令行运行：提供 `--monitor` 持续监控和 `--once` 单次检测模式，也可直接使用 Windows EXE。

## 首次使用

1. 运行 `release/CampusNetLogin.exe`。
2. 输入原始学号和统一身份认证密码，服务选择“中国移动”。已填 `@cmcc` 时不会重复添加；电脑端前缀由门户配置决定，当前现场为 `,0,学号@cmcc`。
3. 电脑连接宿舍路由器时勾选“通过路由器连接”。新配置默认勾选，旧配置保留原直连方式，升级后需自行勾选。
4. 勾选“自动保活与重连”，点击“保存账号”；程序按设置启动监控。也可以点击“一键登录”。只有外网复测成功才显示在线。

[学校学生宿舍上网指南](https://network.njtech.edu.cn/info/1035/1421.htm)确认宿舍支持中国移动，账号为学号，登录密码为自己设置的统一身份认证密码；运营商套餐应先完成绑定。

## 日常运行

- 在线时发送探测流量，不重复登录。单个探测地址故障会尝试其他地址。
- 打开工具后立即检测；已保存中国移动账号并开启自动监控时，认证到期后按需自动登录，无需先打开浏览器。
- 外网全部探测失败后查询门户。在线列表按当前出口 IP 匹配；查询成功码不代表已认证，合法空列表表示需要认证。列表查询无法确认时，再用门户内核核验当前出口：确认未认证才登录，已认证但外网故障时继续检测。两种查询均无法确认时保持状态未知。外网明确重定向到校园门户时按需认证。
- 登录结果分别显示“未提交认证”“认证失败”“认证已接受，等待外网恢复”和“已在线”，只有外网复测通过才显示在线。
- 临时失败等待 30、60、120、240、300 秒，最长 300 秒，恢复后回到 30 秒。密码错误、账号停用、套餐异常会暂停自动认证，修改配置或手动登录后恢复。
- 关闭窗口继续托盘运行；双击托盘图标恢复窗口，托盘菜单或窗口“退出程序”停止。退出时可能需等待当前请求结束。
- 注销和本机下线会先暂停监控；即使保存账号或重新勾选自动选项也保持暂停，直到手动登录。
- “注销并重新登录”串行注销当前出口，再刷新身份并认证。无需持有 `user_index`。
- GUI 和 `--monitor` 共用单实例锁。程序已在运行时第二次启动不会另开认证循环；独立后台模式运行时先停止它，再打开 GUI 修改配置。

连通性流量不能保证延长校园网强制到期会话，到期后以重新认证恢复。电脑睡眠、断电或程序退出期间无法保活。

## 配置和日志

配置保存在 `%USERPROFILE%/.campus_net_login/config.json`；密码使用 Windows DPAPI 加密，保持原存储方式，只能由原 Windows 用户解密。

旧版任一自动选项开启会迁移为 `auto_maintain=true`，两项关闭则保持关闭。新选项保存在 `auto_maintain` 和 `router_mode`，重启后保留服务和选项。直连模式仍使用高级选项 Portal IP，默认 `10.255.20.10:801`；路由器模式从 `http://a.njtech.edu.cn/` 获取当前出口身份及门户配置，不用电脑局域网 IP/MAC 替代。南京工业大学路由器协议中缺少真实 MAC 时，使用门户支持的全零 MAC 占位值；真实 MAC 存在时使用真实值，每次认证都重新获取身份。出口 IP 缺失、身份格式异常/冲突或配置无法解析时，拒绝提交并显示原因。

日志保存在 `%USERPROFILE%/.campus_net_login/logs/monitor.log`，最多保留当前文件及 3 个历史文件。记录掉线发现时间、认证状态、退避和恢复耗时；离线时还记录探测、在线列表计数及内核状态的摘要，无法确定原因时标记“未知”。日志不保存原始在线记录、账号、密码或包含密码的请求 URL，可能包含出口 IP/MAC，分享前可自行遮盖这些设备信息。

## 源码运行及构建

```powershell
python -m pip install -r requirements.txt
python app.py
python app.py --monitor
python app.py --once
```

`--once` 执行一次检测和按需认证，退出码 0 表示外网已验证在线，1 表示未恢复，2 表示已有实例运行、本次未执行检测。`--monitor` 使用保存的配置持续运行，控制台中 Ctrl+C 停止；若关闭自动选项则不自动认证。独立后台运行不会在退出 GUI 后被另外创建。

Windows 下运行 `build.bat`，脚本创建 `build/.venv` 隔离环境、安装依赖、运行测试/编译检查，再生成 `release/CampusNetLogin.exe`。运行 EXE 无需安装 Python。构建工具版本见 `requirements-build.txt`；不需要确认服务器、管理员权限或新增开机任务。

完整本地验收可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify_windows.ps1`。它执行构建、源码检查及真实 EXE 的托盘/锁/退出检查；包测试使用临时空账号配置并只读探测外网，需要当前已联网，未联网时会明确失败。

## 现场验收

1. 电脑通过工具认证，确认同一路由器上的手机同时可以访问外网。
2. 从工具退出，等待校园认证到期；确认电脑和同一路由器手机无法上网。重新打开修正版，保持中国移动、路由器连接和自动监控配置；无需浏览器操作，观察自动认证结果并确认两台设备恢复外网。
3. 电脑和程序持续运行至少 24 小时，包含夜间闲置；记录发现掉线的时间、恢复时间和日志认证状态。
4. 确认强制到期后自动恢复、主动注销不会自动登录、托盘持续运行、退出后停止。
5. 若密码或套餐错误，先修正账号/绑定状态，再保存配置或手动登录。

自动重新认证已由用户现场确认成功。手机共享、完整的退出后到期重启流程和连续 24 小时观察仍需分别验收；一次自动恢复或 24 小时观察不能证明永久不掉线。

验证范围与命令见 [docs/EVIDENCE.md](docs/EVIDENCE.md)，实施规格见 [docs/SPEC.md](docs/SPEC.md)。
